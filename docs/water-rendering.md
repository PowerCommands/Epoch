# Phaser 4 water experiment

Water keeps the baked terrain's original palette, hex insets, and borders. The revised surface has broad travelling swells spanning several hexes, with a crossing swell and slow domain warping that bend and advect its ripple pattern. Moving shaded faces and highlights give the surface more visible volume. Ocean and Coast share the same phases and velocities, so waves do not shear at their boundary; Coast has slightly stronger highlights. A shared shoreline cycle advances a brighter crest and retreats as a wider, dimmer sheet. Detail fades at overview zoom. Habitation animation is unchanged.

`WaterSurface` uses Phaser 4's `Shader` / `ShaderQuad` API ([official shader guide](https://phaser.io/tutorials/phaser-4-shader-guide)). One world-space quad adds one draw per camera, without a filter framebuffer or another world-sized texture. Fragment work is limited to the visible viewport. A nearest-filtered RGBA texture stores one texel per tile: water, shallows, visibility, and valid-map coverage. The current 72×44 saved map uses 12,672 bytes of mask pixels. Animation changes only a time uniform; no water tile iteration, Graphics rebuilding, particles, or texture uploads occur in the frame loop.

The fragment shader uses the same pointy-top axial projection and cube rounding as `HexGridLayout`. Neighbor lookups measure distance to actual land hexes, including their corners, without treating the map boundary as land. This avoids the abrupt wash cutoffs that infinite edge-line distances can produce around headlands. The pattern uses world coordinates, so panning does not drag it across the map and terrain chunk boundaries do not interrupt it. This implementation intentionally targets Epoch's existing hex layout.

Visibility recomputes and temporary map reveal refresh the compact texture; terrain rebakes refresh it through `terrain-rebuilt`. Unseen water is suppressed, including explored tiles under translucent fog. Existing fog, units, resources, borders, rivers, and UI retain their depths. Canvas retains the previous Graphics water implementation. There are no simulation, terrain-data, or save-format changes.

Canvas-backed texture data and Phaser's shader wrappers recover after context restoration. Shutdown removes event subscriptions and destroys the texture and shader. Phaser 4.2.1's Shader destructor does not release its quad buffer and VAOs, so the surface releases those instance-owned wrappers explicitly through Phaser APIs; the shared shader program and index buffer stay owned by Phaser.

Validation: `npm run typecheck`, `npm run build`, and `node tools/waterSurface.browser.mjs` with Vite running at port 5174. The browser harness loads a real saved game, captures in-game and isolated terrain screenshots under `/tmp/epoch-water`, verifies temporal pixel changes, unchanged land/unseen tile centers, visibility uploads, terrain rebakes, context restoration, gameplay save fields, and stable GPU resource counts across scene reload. It also compares CPU render-submission timings with the surface disabled/enabled in alternating order. These are software-renderer measurements, not hardware GPU FPS guarantees.

Use `EPOCH_URL`, `EPOCH_SAVE`, `EPOCH_TEST_OUTPUT`, or `CHROME_PATH` to override harness defaults. The existing `npm run test:phaser-migration:game` covers WebGL and Canvas UI/save reload integration. Dedicated hardware GPU profiling and other browsers remain unverified.

The revised surface passed the saved-game browser harness: 126,113 pixels changed between times 0 and 4 seconds, with a maximum temporal RGB-channel difference of 34/255. All 358 sampled land/unseen centers stayed unchanged. Visibility suppression, terrain rebake, context restoration, save-field preservation, and reload resource counts passed. The renderer retained 10 buffers and 7 VAOs, with one water texture and one terrain-refresh listener. Strict typechecking and production build passed (the existing Vite bundle-size warning remains). The earlier WebGL/Canvas integration validation still covers the unchanged ownership and fallback paths.

The revised surface also passed on the built-in **200×75 World map**, spanning multiple terrain chunks, with `EPOCH_SCENARIO=map_world EPOCH_TEST_OUTPUT=/tmp/epoch-water-world node tools/waterSurface.browser.mjs`. Its mask is 60,000 bytes. Temporal motion changed 21,712 pixels with a maximum channel difference of 32/255; 313 land/unseen centers stayed unchanged. Context restoration and reload resource counts passed. Alternating off/on/on/off CPU submission medians were all 8.6 ms (p95 8.9/8.9/9.1/9.0 ms) on ANGLE/SwiftShader at 1440×900. This measures CPU submission on a software renderer, not hardware GPU frame time.
